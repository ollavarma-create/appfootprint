# AppFootprint v0.2.0

**Understand before you remove.**

AppFootprint is a read-only Linux desktop application for exploring application storage and investigating disk usage. It does not delete files.

## Highlights

- Flatpak application and runtime inventory, including shared dependencies.
- Experimental Snap and RPM inventory.
- User Storage and Storage Investigator views for examining storage usage.
- Navigation, sorting, scan progress, cancellation, and explanatory cleanup guidance.
- No administrator privileges required for normal use; no telemetry or automatic cleanup.
- Experimental x86_64 AppImage package.

## Validation

- 139 Python tests passed on Fedora KDE (reported during release preparation).
- GitHub Actions AppImage build and headless launch smoke test passed.
- The AppImage was manually tested on Fedora KDE.
- Source-tree security review completed; supply-chain checks improved.

## Security and limitations

- AppImage packaging tool and runtime are pinned to fixed releases and checked against SHA256 digests before use.
- This is not a formal security certification or a reproducible build.
- Transitive Python and operating-system build dependencies are not fully hash-locked.
- Storage figures reflect allocated file blocks and are not guaranteed to represent uniquely recoverable disk space.
- Distribution coverage beyond Fedora KDE remains limited.

## Installation

Download `AppFootprint-x86_64.AppImage` and `AppFootprint-x86_64.AppImage.sha256` from the GitHub Release assets, verify them, then run:

```bash
sha256sum -c AppFootprint-x86_64.AppImage.sha256
chmod +x AppFootprint-x86_64.AppImage
./AppFootprint-x86_64.AppImage
```

The checksum file and AppImage should be obtained from the same intended release. Review the source and build provenance if a stronger trust model is required.
